## 🎯 What is Script-CMS?

Script-CMS is a flat-file content management system designed for everyday people. It is a fast, simple, and practical solution for creating and managing websites without learning programming languages, databases, or complex configuration files. Whether you need a personal blog, a small business site, or a portfolio, Script-CMS runs entirely on your own web server or hosting service — no database setup, no backend fuss.
